# LifeFlow Dashboard

A modern productivity dashboard built with HTML, CSS, and Vanilla JavaScript to help users organize their daily activities through task management, focus sessions, and quick website access.
---

## Features

### Greeting Section

* Real-time clock
* Current date display
* Dynamic greeting based on time of day
* Custom user name support

### Focus Timer

* 25-minute Pomodoro timer
* Start timer
* Stop timer
* Reset timer

### To-Do List

* Add tasks
* Edit tasks
* Mark tasks as completed
* Delete tasks
* Save tasks using Local Storage

### Quick Links

* Add favorite websites
* Open links in a new tab
* Delete links
* Save links using Local Storage

---

## Selected Challenges

### 1. Light / Dark Mode

Users can switch between light mode and dark mode. Theme preferences are automatically saved using Local Storage.

### 2. Custom Name in Greeting

Users can personalize the dashboard by entering their name, which will be displayed in the greeting section.

### 3. Sort Tasks

Tasks can be sorted using the following options:

* Pending First
* Completed First
* A-Z
* Z-A

## Local Storage Usage

The application stores the following data locally in the browser:

* User name
* Tasks
* Task completion status
* Quick links
* Theme preference

No backend server or external database is required.
