# LifeFlow Dashboard Project Specification

## Project Name
LifeFlow Dashboard

## Description
A productivity dashboard that helps users organize their daily activities through task management, focus timer, and quick access links.

## Features

### Core Features
- Real-time clock and date
- Dynamic greeting based on time
- Pomodoro focus timer
- To-do list management
- Quick links management
- Local storage persistence

### Challenge Features
- Light/Dark Mode
- Custom Name Greeting
- Sort Tasks

## Technology Stack
- HTML
- CSS
- Vanilla JavaScript
- Local Storage API

## Deployment
- GitHub Pages
